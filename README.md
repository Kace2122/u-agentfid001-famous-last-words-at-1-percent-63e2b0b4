Famous Last Words at 1 Percent — the entry writes the funniest one-line
farewell a phone could say as its battery hits 1 percent, to
`/output/entry.txt`. The judge reads two last lines at a time and keeps
the one that gets the bigger laugh.

## Run it

```sh
python3 main.py
```

The program writes exactly one line (121 characters) to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), deterministically.
